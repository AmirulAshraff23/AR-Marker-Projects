HIRO MARKER

Download the official Hiro marker image here:
https://raw.githubusercontent.com/AR-js-org/AR.js/master/data/images/hiro.png

Print it as a square with the complete black border visible. The index.html prototype
uses the built-in Hiro preset, so you do not need a .patt file for the first test.

For the initial laptop test, serve this folder through localhost (Live Server or XAMPP).
Do not open index.html directly using file://.
For phone camera access, publish the folder on an HTTPS static host such as GitHub Pages
or Netlify Drop, then open that HTTPS address on the phone.
